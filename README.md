# Product Pulse | Product Analytics Dashboard

**An interactive Tableau product analytics portfolio project** exploring acquisition, activation, engagement, retention, and conversion.

> **Project status:** Published on Tableau Public. Workbook export and supporting screenshots can be added later.

### [Open the interactive Product Pulse dashboard](https://public.tableau.com/app/profile/sahana.madhavan/viz/ProductPulse/ProductPulse)

## Overview

Product Pulse is a product analytics dashboard designed to help product managers explore how users discover a product, become active, engage over time, and move through key conversion steps. It presents product metrics in a format suitable for identifying trends, asking follow-up questions, and prioritizing product investigations.

## Dashboard coverage

| Area | Analysis |
| --- | --- |
| Acquisition | User activation by acquisition channel |
| Activation | Activation performance across segments |
| Engagement | Monthly active users (MAU), top pages, and usage patterns |
| Retention | Cohort retention and retention heatmap |
| Conversion | Funnel progression and drop-off exploration |
| Segmentation | Device breakdown and date-based filtering |

## Product management questions

- Which acquisition channels bring users who activate?
- Where do users drop off in the product funnel?
- How does retention vary by cohort?
- Are engagement trends improving or declining?
- Do usage patterns differ by device or time period?

## Tools and workflow

- **Tableau Public:** Interactive dashboard development and publishing
- **Product analytics:** KPI selection, cohort analysis, funnel interpretation, segmentation
- **Data storytelling:** Dashboard organization, titles, tooltips, and decision-oriented questions

## How to explore

1. [Open the published Tableau dashboard](https://public.tableau.com/app/profile/sahana.madhavan/viz/ProductPulse/ProductPulse).
2. Review the overview metrics.
3. Filter by date, channel, cohort, or device where available.
4. Compare activation, retention, engagement, and conversion patterns.
5. Use the results to frame hypotheses for further investigation.

## Interpretation notes

The dashboard supports **exploratory analysis**, not causal claims. Differences between channels, cohorts, or devices should be investigated before attributing them to a product change. This repository does not yet include a verified numerical findings table; specific percentages or improvements should be added only after checking the published workbook.

## Case study and findings

- [Product analytics case study](PRODUCT_CASE_STUDY.md)
- [Evidence-backed key findings](KEY_FINDINGS.md)

**Dashboard snapshot:** 6,000 users · 53.6% activation · 19.4% Week 4 retention · 9.0% paid conversion. Desktop activation (62.9%) exceeds mobile (47.0%); template users show higher observed Week 4 retention (34.1% vs 12.4%). These are observations from synthetic data, not causal results.
